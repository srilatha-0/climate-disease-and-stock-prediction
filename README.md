# 🌍 Climate Impact on Stock & Dengue Prediction

## 📌 Overview

This project analyzes the relationship between **climate conditions** (temperature, rainfall, humidity) and their impact on **stock trends and dengue outbreaks** using machine learning models.

It combines multiple real-world datasets and performs end-to-end data processing, feature engineering, and prediction.

---

## 🛠️ Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib
* Streamlit

---

## 📊 Dataset

This project uses a combination of:

* Historical climate data (1981–2014)
* Stock market data from Yahoo Finance

⚠️ Due to preprocessing and dataset size, the final merged dataset is not included in this repository.

📩 **Dataset Access:**
If you want to run this project, feel free to contact me and I’ll share the dataset or guide you on how to recreate it.

---

## ⚙️ Data Processing

* Cleaned missing and inconsistent values
* Merged multiple datasets based on time alignment (monthly/quarterly)
* Created features like temperature trends, rainfall patterns, and humidity levels

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/srilatha-0/your-repo-name.git
cd your-repo-name
```

### 2. Navigate to backend

```bash
cd backend/src
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
